# Fuentes del design system La Zuricata v3

Los archivos de fuente no se suben a este repo (pesan ~6.4 MB en total, más que el límite de 5 MB para esta carpeta). Ambas familias están bajo SIL Open Font License 1.1.

Archivos usados por `zuricata_style_v3.py`:

- Iosevka Charon Mono (títulos, rótulos, números; OFL 1.1, © 2025 the Iosevka Project authors): IosevkaCharonMono-Light.ttf, -Regular.ttf, -Medium.ttf, -Bold.ttf. Fuente: https://github.com/be5invis/Iosevka/releases y Google Fonts.
- Manrope (cuerpo; OFL 1.1, © 2018 The Manrope Project Authors): Manrope-Light.ttf, -Regular.ttf, -Medium.ttf, -SemiBold.ttf, -Bold.ttf, -ExtraBold.ttf. Fuente: https://fonts.google.com/specimen/Manrope y https://github.com/googlefonts/manrope.

En el sitio ya se cargan vía npm: `@fontsource/iosevka-charon-mono` y `@fontsource-variable/manrope` (ver `src/styles/global.css`).
