El problema

El chatbot tiene límites

Un chatbot es poderoso. Pero sigue siendo solo una conversación.

Lo que puede hacer

Responder preguntas con mucho contexto

Escribir código, emails, resúmenes

Traducir y reformatear contenido

Explicar conceptos complejos

Lo que NO puede hacer

Ejecutar acciones en el mundo real

Buscar información actualizada

Coordinarse con otros sistemas

El chatbot responde. Pero cuando cerrás la ventana, olvidó todo y no hizo nada.

El agente principal coordina. Los sub-agentes ejecutan en paralelo.

Glosario · Parte 1

Las piezas que vimos

Para que te lleves los conceptos claros cuando te vayas.

🧠 LLM Large Language Model

Un modelo entrenado con billones de textos que aprende a predecir qué palabra viene después. No piensa: completa. ChatGPT, Claude y Gemini son LLMs.

🤖 Agente AI Agent

Un LLM con autonomía y herramientas. Recibe un objetivo, planifica los pasos, ejecuta acciones en el mundo real y reporta. Trabaja sin que lo guíes paso a paso.

🎯 Orquestador Agent Runtime

La plataforma donde corre el agente. Le da contexto, ejecuta sus skills, coordina sub-agentes y conecta con el mundo. Claude Code y OpenClaw son orquestadores.

🛠️ Skill Capacidad

Una habilidad específica que le enseñás al agente. Es un archivo Markdown con instrucciones: "cuándo activarte y qué hacer". Cualquiera puede escribir una.

🤝 Sub-agente Subagent

Un agente especializado al que el agente principal delega tareas en paralelo. Frontend, backend, security: cada uno con su contexto propio. Acelera el trabajo.

⌨️ CLI Command Line Interface

La terminal. La ventana negra con texto donde los developers escriben comandos en vez de hacer click. Claude Code es una CLI.

Glosario · Parte 2

Protocolos, memoria y vocabulario

Lo invisible que hace funcionar todo. Y el vocabulario que vas a escuchar en cualquier conversación de devs.

🔌 MCP Model Context Protocol

El USB de los agentes. Un estándar abierto creado por Anthropic para conectar el agente con herramientas: GitHub, Slack, bases de datos, calendarios. Si existe, hay un MCP.

📡 ACP Agent Communication Protocol

El idioma común entre agentes. Permite que un agente de Anthropic le hable a uno de Google sin código intermedio. IBM, Cisco y Salesforce ya lo adoptaron.

💾 Engram Memoria persistente

La memoria que sobrevive entre sesiones. Sin Engram, el agente empieza cada conversación desde cero. Con Engram, recuerda decisiones, bugs resueltos y tus preferencias.

🗂️ Vault Grafo de conocimiento

Una biblioteca de notas enlazadas (Obsidian). El agente la consulta como segunda mente: documentación, decisiones de arquitectura, runbooks, patrones del equipo.

🌐 Open source Código abierto

Software cuyo código es público, modificable y gratuito. Cualquiera puede leerlo, mejorarlo o adaptarlo. MCP, ACP, Engram y OpenClaw son open source.

📁 Repo · PR · Issue GitHub básico

Repo: carpeta del proyecto con su historial. Issue: una tarea o bug reportado. PR (pull request): propuesta de cambios para revisar antes de mergear.
