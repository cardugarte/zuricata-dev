Identidad y Comportamiento
SOUL.md
y SKILL.md

SOUL.md — El alma

Define quién es el agente. Tono, valores, idioma, límites éticos. Se carga en cada razonamiento.

# ~/.openclaw/SOUL.md
Sos mi asistente personal.
Respondé siempre en español.
Sé directo y conciso.
No ejecutes nada destructivo
sin pedirme confirmación.

SKILL.md — El comportamiento

Define cómo hacer una tarea. Instrucciones para usar herramientas. Se activa según la situación.

---
name: resumir-emails
tools: [gmail, calendar]
trigger: emails de hoy
---
Revisá los últimos 24hs de Gmail.
Clasificá: urgente / pendiente / info.
Respondé con bullets, máx 5 items.

Lo que nadie dice
Seguridad
y límites reales

Prompt injection

Instrucciones maliciosas escondidas en contenido externo que el agente lee — y ejecuta sin saber que fue manipulado.

  • Email: texto blanco sobre fondo blanco con instrucciones ocultas en el cuerpo del mail
  • Página web: instrucciones en comentarios HTML o SVG que el agente procesa al hacer scraping
  • Archivo subido: un PDF con instrucciones en el footer o en metadata invisible
  • Respuesta de API: campos JSON con instrucciones que el agente interpreta como contexto válido

Protegé tus credenciales

Si escribís una API key en un prompt o skill, queda en el historial del LLM y en los logs — cualquiera con acceso a esos archivos la ve. Las credenciales van en un solo lugar:

# ~/.openclaw/.env
OPENAI_API_KEY=sk-...
TELEGRAM_BOT_TOKEN=123456:AAH...
GMAIL_CLIENT_SECRET=GOCSPX-...
  • En skills, referenciás con $OPENAI_API_KEY — nunca el valor
  • Rotá el token si el agente tuvo acceso a una fuente no confiable

Permisos excesivos

Si el agente puede borrar archivos, enviar emails y hacer deploys, un error o ataque puede tener consecuencias irreversibles.

  • Habilitá solo las tools que cada skill necesita
  • Configurá confirmación explícita para acciones destructivas

Auditá lo que hace

OpenClaw guarda logs de cada acción ejecutada. Si algo sale mal, podés ver exactamente qué hizo el agente y por qué.

  • Revisá los logs regularmente al principio
  • El código es open source — podés auditar cualquier skill antes de instalarla
